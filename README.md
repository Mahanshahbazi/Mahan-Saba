# 🐘 Just for Her — Autumn Mystery V2

یک تجربه‌ی فارسی، راست‌به‌چپ و موبایل‌محور از یک بازی عاشقانه با فیل کوچولوی خاکستری، داستان شاخه‌ای، دعوت‌نامهٔ پاییزی و دفتر خاطرات.

## اجرای محلی (Windows / PowerShell)

Node.js 20 یا جدیدتر نصب باشد. در پوشه‌ی `just-for-her`:

```powershell
npm.cmd install
npm.cmd run dev
```

آدرس نمایش‌داده‌شده را در مرورگر باز کنید (معمولاً `http://localhost:5173`). از `npm.cmd` استفاده کنید اگر PowerShell اجرای `npm.ps1` را مسدود کرده است.

## ساخت نسخه انتشار

```powershell
npm.cmd run build
npm.cmd run preview
```

خروجی build در `dist/` ذخیره می‌شود. اگر وابستگی‌ها روی سیستم شما دانلود شده باشند، این دستورات باید اجرا شوند.

## شخصی‌سازی مهم

فقط فایل `src/config.ts` را باز کنید و تنظیمات زیر را تغییر دهید:

- `herName` و `myName` برای نام‌ها
- `welcome` و `secretNote` برای خوشامد و نامه‌ی مخفی
- `fastFoodRestaurant`: «لیتل ایتالی»
- `unknownIranianRestaurant`: عنوان رستوران ایرانی که نامش هنوز معلوم نیست
- `favoriteCafe`: «کافه تایپ»
- `favoritePastryShop`: «شیرینی فرانسه»
- `saffronPastryShop`: «شیرینی زعفرانیه»
- `invitationDate` و `finalNote`
- `choices` برای واژه‌بندی سؤال‌ها و گزینه‌های بازی

### منطق سورپرایز

- صفحه‌های ابتدایی، *اسم مکان‌ها را نشان نمی‌دهند*. انتخاب‌ها بر پایه حس‌وحال، مزه‌ها و نوع صحنه‌اند.
- فست‌فود → لیتل ایتالی.
- ایرانی → «همون رستوران ایرانی که قرار بود با هم بریم» تا وقتی اسمش را مشخص کنید.
- کافه‌ی دنج → کافه تایپ.
- شیرینی‌فروشی نوستالژیک → شیرینی فرانسه.
- شیرینی زعفرونی → شیرینی زعفرانیه.
- برای نوشیدنی هات‌چاکلت، لاته، چای، ماسالا، قهوه، نوشیدنی خنک و انتخاب سورپرایزی وجود دارد.
- هات‌چاکلت پاییزی **همیشه پیشنهاد عاشقانهٔ جداگانه** در دعوت‌نامه است، اما انتخاب نوشیدنی او هم حفظ می‌شود.
- گزینه‌های «هیچی نمی‌خوام» و «نه» محترم‌اند و مسیرشان به پاسخ آرام ختم می‌شود.
- درد زیاد یا انرژی پایین، متن پیشنهاد را نرم‌تر می‌کند؛ تصمیم‌گیری نهایی با مخاطب است.

## ذخیره خاطرات و حریم خصوصی

خاطرات و عکس‌ها به شکل محلی در `localStorage` مرورگر ذخیره می‌شوند. عکس قبل از ذخیره کوچک و JPEG می‌شود تا مصرف فضا کاهش پیدا کند. با پاک‌کردن داده مرورگر خاطرات ممکن است پاک شوند. دکمهٔ «پشتیبان» یک فایل JSON با خاطرات و عکس‌های تعبیه‌شده در آن می‌سازد. ذخیره ابری و ارسال خودکار وجود ندارد. دکمهٔ اشتراک‌گذاری از قابلیت دستگاه استفاده می‌کند یا متن را کپی می‌کند.

**نکته:** `localStorage` فقط برای همان مرورگر/دستگاه است؛ اطلاعات روی موبایل پارتنر، خودبه‌خود روی دستگاه شما نمایش داده نمی‌شود. برای دریافت بلیت باید آن را خودش با شما به اشتراک بگذارد.

## انتشار رایگان روی Vercel

1. پروژه را در یک مخزن GitHub آپلود کنید.
2. در Vercel گزینهٔ Add New Project و مخزن را انتخاب کنید.
3. Framework Preset: Vite؛ Build Command: `npm run build`؛ Output Directory: `dist`.
4. Deploy را بزنید و URL تولیدشده را برای او بفرستید.

برای Netlify هم Build Command: `npm run build` و Publish Directory: `dist` است.

## فایل‌های اصلی

- `src/App.tsx` — حالت‌ها و مسیرهای بازی، بلیت، ذخیره و اشتراک‌گذاری
- `src/config.ts` — همه نام‌ها، مکان‌ها و انتخاب‌ها
- `src/Elephant.tsx` — فیل SVG با احساسات مختلف
- `src/styles.css` — طراحی و انیمیشن‌ها
- `index.html` — فونت‌ها و تنظیمات صفحه

## تست

سورس TSX با کامپایل نحوی TypeScript بررسی شده است. نصب بسته‌ها در محیط تولید به دلیل عدم دسترسی کامل به registry به پایان نرسیده؛ بنابراین اجرای مرورگر و build کامل اینجا تأیید نشده‌اند. روی ویندوز ابتدا `npm.cmd install` و سپس `npm.cmd run build` را اجرا و خروجی هر خطایی را بررسی کنید.

## نسخه V3 — بلیت تصویری و گزارش با رضایت
- «شیرینی زعفرانیه» در بازی به **دانمارکی‌های خوشمزه** مرتبط شده است، نه شیرینی زعفرانی.
- پس از اتمام داستان، دکمه «بلیط رو بهم بده» یک تصویر PNG با پس‌زمینه عاشقانه، تصویر فیل خاکستری، مقصد و انتخاب‌ها دانلود می‌کند. کاربر باید فایل را **خودش** در تلگرام ارسال کند.
- دکمه گزارش اختیاری مسیر بازی، فایل `our-date-game-report.json` را از روی انتخاب‌ها و مسیر ثبت‌شده در همین مرورگر می‌سازد. در گوشی‌هایی که اشتراک فایل را پشتیبانی می‌کنند، پنجره اشتراک‌گذاری دستگاه را باز می‌کند؛ وگرنه فایل دانلود می‌شود.
- **هیچ ارسال خودکار، ایمیل مخفی، جمع‌آوری سروری یا ردیابی پنهانی وجود ندارد.** چون داده‌ها ممکن است شامل حال جسمی و احساسات باشند، ارسال گزارش صرفاً با اقدام و رضایت آگاهانه خود فرد انجام می‌شود.
- برای ایمیل خودکارِ با رضایت، باید بعداً یک سرویس سمت سرور/ایمیل و صفحه رضایت و تنظیمات امن آن اضافه شود. اطلاعات حساس را داخل کد کلاینت، سرویس‌های ناشناس یا توکن عمومی قرار ندهید.
